# mini-4wd-webapp
ミニ四駆自動運転車をスマートフォン等のブラウザから遠隔操作・監視するためのWebアプリケーション (シンプル・ライトテーマ・モノクロ)

---

## 主な特徴

- **モバイルファースト & 見やすい大文字UI:**
  - スマホの画面でも屋外や片手持ちでしっかり確認できるフォントサイズと大きなタップターゲット。
- **完全モノクローム & ライトテーマ (Monochrome Light Theme):**
  - 有彩色（赤・青・黄等）を全廃し、白・黒・グレーのみで構成されたクリーンなライトテーマ。
  - 余計な装飾を極限まで削ぎ落とした、視界を妨げないミニマルHUD。
- **直感的な統合2D仮想ジョイスティック:**
  - 画面上の任意の場所をタッチ＆ドラッグするだけで、1本の親指で前後（スロットル）と左右（ステアリング）を同時制御。
  - 指を離すと即座にニュートラル・停止へ自動復帰。
  - PCブラウザでもマウスドラッグで同様に操作可能。
- **堅牢な安全機能:**
  - 最優先「STOP」ボタン（停止後は「RESET」ボタンへ自動切り替え）
  - 運転引継ぎ警告（TOR）のリアルタイムカウントダウン & 手動引継ぎ（TAKE OVER）ボタン
  - 通信途絶時の自動切断検知 & 再接続ループ
  - マイコンの確定状態を同期する Source of Truth 設計

---

## 起動・利用手順

マイコン（`mock_server.py`）が **Web操作画面の配信（HTTP）** と **リアルタイム制御通信（WebSocket）** の両方を同一ポート（8765）で提供します。

### 1. サーバーを起動
```bash
python3 mock_server.py
```
- ポート `8765` で Webサーバー＆WebSocketサーバーが起動します。
- ターミナル上で `1` 〜 `5` のキーを押すことで、動作シナリオ（手動走行、自動運転、TOR警告、障害物検知、非常停止）をリアルタイムに切り替えられます。

### 2. ブラウザ（スマホまたはPC）でアクセス
スマホやPCのブラウザで以下のURLを開きます：
👉 **http://<サーバーのIPアドレスまたはlocalhost>:8765**

- 画面の任意の場所をタッチ（またはマウスクリック）してスワイプすることで走行操作が可能です。
- 右上の「INFO」ボタンからいつでも操作説明を確認できます。
